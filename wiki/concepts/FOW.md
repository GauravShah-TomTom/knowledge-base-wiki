# FOW (Functional Order of Way)

FOW is a road classification attribute used in map data to describe the function of a road within the overall road network. In the [[projects/Lanes]] pipeline, FOW is used to classify junction types — for example, FOW 3 identifies T-junctions (3-valent junctions) where default lane connectivity logic is applied (see [[decisions/Default Lane Connectivity at 3-Valent T-Junctions]]).
