# Agentic Coding

The practice of using AI coding agents (such as Claude Code, GitHub Copilot, or IDE-integrated agents) to autonomously or semi-autonomously implement, test, debug, and review code — beyond simple code completion.

## Key capabilities expected

- Reading and understanding codebase context
- Implementing user stories and tasks end-to-end
- Writing tests
- Debugging from logs and stack traces
- Updating documentation when code changes
- Reviewing PRs for adherence to coding guidelines

## Guidelines (being defined as of 2026-05)

The team is working on "Agentic Coding Guidelines" (action item IN_PROGRESS) covering:
- Project-specific coding guidelines for agents
- Uniform agent behavior across developers
- Safety best practices for agents
- Guard rails for agentic coding
- Agent PR review for adherence to guidelines
