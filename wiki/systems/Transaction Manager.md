# Transaction Manager

Transaction Manager is a web service in the [[Lanes]] pipeline that converts output JSON files from [[Lanes Automator]] into map change transactions and sends them to [[MCR]].

## Interface

- Exposes a REST API; called once per [[H3 Tiles|H3 tile]] to process each tile's JSON output.
- For a zone split into N tiles, N REST API calls are made (in parallel in the planned end-to-end flow via [[Airflow]]).

## Transaction metadata

Each transaction is linked to its source JSON. A database row records the JSON-to-transaction mapping. The pipeline also stores rule metadata in the JSON (which [[DTFR]] rule was applied), enabling traceability.

Planned: populate an [[Iris]] priority field when creating tasks, based on whether the transaction was generated by a default rule — see [[decisions/Use Iris Priority Field for Rule-Specific Transactions]].
