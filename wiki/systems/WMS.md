# WMS

TomTom-internal Web Map Service used to visualise FCD (Floating Car Data) sign observations. Displays per-sign seen/not-seen sector data as colour-coded overlays (green = observed from that direction, red = not observed).

Accessible via the FCD test-demo endpoint: `test-demo.wms.fcd.tt3.com`.
