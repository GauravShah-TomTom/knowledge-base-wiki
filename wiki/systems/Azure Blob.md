# Azure Blob

Microsoft Azure Blob Storage used by the [[Team Wiki]] platform as the raw files container. Team members upload notes, transcripts, emails, and scan images here via the Next.js upload UI; the scheduled wiki-ingest GitHub Action reads from this container to generate wiki pages.

## Related systems

- [[Team Wiki]] — the platform that reads from this container
- [[Azure AI Search]] — downstream indexed output
