# Claude Code

Anthropic's AI coding assistant (CLI tool and IDE extension). Used by team members to interact with the [[Team Wiki]] platform and broader development workflows via Git and [[MCP]] connectors.

- Team members use Claude Code to run wiki ingestion, query the knowledge base, and author new wiki pages through the MCP server exposed by the [[Team Wiki]] Next.js app.
