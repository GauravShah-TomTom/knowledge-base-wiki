# Data Preparator

Data Preparator is an upstream component in the [[Lanes]] pipeline that runs on [[Databricks]]. It prepares the input data for lane derivation, already processing data in parallel across [[H3 Tiles|H3 tiles]].

Data Preparator runs together with [[Cross Link]] as part of the Databricks job that precedes [[Lanes Automator]].
