# Systems - index
[[wiki/index|← Index]]

Our products, platforms, and services.

- [[wiki/systems/Airflow|Airflow]] — Apache Airflow pipeline orchestration tool used for managing data processing pipelines.
- [[wiki/systems/Atlassian Rovo|Atlassian Rovo]] — AI-powered platform by Atlassian that provides custom agents and automation capabilities within the Jira and Confluence ecosystem.
- [[wiki/systems/Confluence|Confluence]] — Atlassian wiki and documentation platform used for design proposals, architecture documentation, sprint review pages, and process documentation.
- [[wiki/systems/Core DB|Core DB]] — Internal map database service that stores the world map as a sequence of changes (deltas) and periodic snapshots.
- [[wiki/systems/Databricks|Databricks]] — Data engineering platform used for scalable pipeline execution.
- [[wiki/systems/Genesis|Genesis]] — Lane derivation system that processes [[HD Map|HD]] and [[Orbis]] source data to generate lane-level map features, including lane connectivity, direction of traffic flow, and divider types.
- [[wiki/systems/ID Index Service|ID Index Service]] — Dedicated Go service that replaces the in-PostgreSQL [[ID Index]] in [[Core DB]], providing faster and more memory-efficient feature-ID-to-dataset lookups.
- [[wiki/systems/Jira|Jira]] — Atlassian project management tool used for sprint planning, backlog management, and task tracking.
- [[wiki/systems/Orbis|Orbis]] — HD map data source system that provides lane geometry, centerlines, trajectories, and connectivity information used as input for lane derivation in the [[Lanes FMO]] pipeline.
- [[wiki/systems/Playwright MCP|Playwright MCP]] — MCP (Model Context Protocol) server by Microsoft that enables Claude to automate browser interactions through the page's accessibility tree rather than screenshot-based vision models.
