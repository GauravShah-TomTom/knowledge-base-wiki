# Atlassian Rovo

AI-powered platform by Atlassian that provides custom agents and automation capabilities within the Jira and Confluence ecosystem.

## Usage in AI First SDLC

The team is exploring Rovo as a primary tool for automating SDLC workflows, particularly:
- **KR → Epics**: automatically generate Jira Epics from OKR/KR description bullets (Atlas Goals)
- **Epic → Backlog**: create user stories under Epics with HITL (Human-in-the-Loop) review
- **Sprint grooming**: build and refine stories from meeting discussions and messages
- **Sprint planning**: log tasks for stories and delegate creation to Rovo with relevant context
