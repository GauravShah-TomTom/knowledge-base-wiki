# Cross Link

Cross Link is a processing component that runs on [[Databricks]] alongside [[Data Preparator]] as part of the [[Lanes]] pipeline. It processes cross-link data in parallel across [[H3 Tiles|H3 tiles]], feeding into [[Lanes Automator]].
